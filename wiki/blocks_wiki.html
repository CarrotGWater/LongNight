CarrotS 方块

CarrotS 包中的方块定义 · 基于 blocks.json 数据驱动

CarrotS 是长夜项目的一个基础资源包，该项目以此资源包为核心资源构建。 每个方块通过 JSON 配置其属性，包括硬度、透明度、纹理、掉落物、声音等。 所有方块都继承自 ID_default 中的默认值，仅有差别的字段需要显式覆盖。

💡 数据驱动提示： 当某个属性（如 physics.hardness）未在具体方块中定义时，游戏会回退使用 ID_default 中的默认值。这意味着每个方块只需定义与其默认值不同的字段即可。 例如 grass 只覆写了 sources.texture 和 interaction.drops， 其余 15+ 个属性全部继承自 ID_default。

空气 Air

空气（Air）是构成世界中空白空间的方块。它完全透明，硬度为 0， 不需要任何工具即可被瞬间破坏（实际上不可被选中破坏）。

ID ID_000000
physics.transparent ✅ true
physics.hardness 0.0 (覆写默认 1.0)
interaction.drops 无 (继承默认但空气不可破坏)
sources.texture 无纹理 (继承默认 missing.png，但不会渲染)
其余字段 全部继承自 ID_default

草方块 Grass

草方块（Grass）是覆盖在大多数陆地生物群系表面的方块。 使用适当的工具（如锹）采集可获得自身。在不使用工具徒手挖掘时，仍会掉落自身。

ID ID_000001
physics.transparent ❌ false (继承默认)
physics.hardness 1.0 (继承默认)
sources.texture "grass.png" (覆写默认)
interaction.drops ["grass"] (覆写默认)
physics.flammable ❌ false (继承默认)
其余字段 全部继承自 ID_default

石头 Stone

石头（Stone）是地下最常见的固体方块。采集后会掉落自身。 在后续更新中，使用精准采集附魔或许可以获得石头本身，否则可能会掉落圆石（待定）。

ID ID_000002
physics.transparent ❌ false (继承默认)
physics.hardness 1.0 (继承默认)
sources.texture "stone.png" (覆写默认)
interaction.drops ["stone"] (覆写默认)
interaction.tool_type "empty" (继承默认，暂未定义推荐工具)
其余字段 全部继承自 ID_default

默认模板 ID_default

ID_default 是一个特殊的条目，它不是可放置的方块， 而是为所有方块提供默认属性值。 当某个方块未定义特定字段时，游戏会回退使用此处的值。

📋 注意： ID_default 本身的 name 为 "CarrotS_NONE"， 这表示它仅作为配置模板，在实际游戏中不会出现。

属性详解

以下按照 blocks.json 的实际结构，分 physics、sources、interaction 三个分组逐一说明。

name — 名称（顶层字段）

方块的标识名称，位于 JSON 根层级。例如 "air"、"grass"、"stone"。
ID_default 的 name 为 "CarrotS_NONE"，表示它仅作为默认模板。

▸ physics — 物理属性组

包含 8 个子字段，控制方块的硬度、透明度、可燃性、碰撞箱、物态、重力、速度修正、跳跃修正。

physics.hardness — 硬度

数值越高，挖掘时间越长。计算公式参考 Minecraft：
挖掘时间 = hardness × 1.5 / 工具速度（待确认）。
空气的硬度为 0，可瞬间破坏。

physics.transparent — 透明度

若为 true，则光线可以穿过该方块，且方块侧面不会被渲染（类似玻璃、空气）。
目前只有空气的 ID_000000 显式设置了 true。

physics.flammable — 可燃性

若为 true，该方块可被火焰点燃并蔓延。目前所有方块均不可燃（默认 false）。

physics.integrity — 完整性

控制方块的碰撞箱与外观形态。"A_full" 表示完整的 1×1×1 方块。未来可能支持台阶 ("slab")、楼梯 ("stair") 等。

physics.state_of_matter — 物态

物理状态：solid（固体）、liquid（液体）、gas（气体）。影响方块的流动与碰撞行为。

physics.gravity — 重力

该方块的重力倍率，影响掉落中的实体或受重力影响的方块（如沙砾）的下落速度。

physics.speed_modifier — 速度修正

玩家在该方块上行走的速度倍率。1.0 为正常速度。可用来制作减速方块（如蛛网 < 1.0）或加速方块（如冰 > 1.0）。

physics.jump_modifier — 跳跃修正

玩家在该方块上跳跃的高度倍率。1.0 为正常跳跃高度。

▸ sources — 视觉 & 声源组

包含 6 个子字段，控制纹理、地图颜色、光照等级、三种声音。

sources.texture — 纹理

方块使用的纹理文件路径（相对于 textures/ 目录）。默认值为 "missing.png"（缺失纹理占位图）。
各方块覆写：grass → "grass.png"，stone → "stone.png"。

sources.map_color — 地图颜色

在游戏地图上该方块所呈现的颜色（十六进制 RGB）。例如默认 "#888888" 为灰色。

sources.light_level — 光照等级

方块自身发出的光照强度，范围为 0–15。0 表示不发光。未来发光的方块（如荧石、火把）将使用此属性。

sources.sound_break — 破坏音效

破坏（挖掘）该方块时播放的声音。默认 "block_break"。

sources.sound_place — 放置音效

放置该方块时播放的声音。默认 "block_place"。

sources.sound_step — 行走音效

玩家在该方块上行走时播放的声音。默认 "block_step"。

▸ interaction — 交互属性组

包含 3 个子字段，控制工具类型、掉落物、方块实体。

interaction.tool_type — 工具类型

推荐的挖掘工具，"empty" 表示空手即可。未来可能扩展为 "pickaxe"（镐）、"shovel"（锹）、"axe"（斧）等。

interaction.drops — 掉落物

字符串数组，指定方块被破坏后掉落的物品 ID。默认掉落 ["CarrotS_block:0"]。
各方块覆写：grass → ["grass"]，stone → ["stone"]。

interaction.tile_entity — 方块实体

如果此方块需要存储额外数据（如箱子中的物品、熔炉的进度），则在此指定绑定的 TileEntity 类名。当前所有方块均为 null。

未来规划

  • 更多基础方块：泥土、木头、沙砾、沙子、水、熔岩等
  • 多面纹理支持（侧面/顶部/底部使用不同的纹理）
  • 方块状态（如方向、含水、年龄等）
  • Loot Table 独立配置掉落物与条件
  • 方块标签（Block Tags）系统
  • 自定义声音资源（sounds/ 目录）
